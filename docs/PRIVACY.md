# 发布内容与数据隐私

本仓库只发布独立参考版，不连接或同步原作者的个人工作台数据。

本次公开文件逐项来自源码、说明、测试、合成示例和示例截图白名单。未包含真实姓名、私人联系方式、个人机器目录、简历、真实投递记录、聊天日志、访问凭据、浏览器资料、模型权重或虚拟环境。截图仅显示合成记录，未包含浏览器地址栏或其他标签页。

公开提交使用 GitHub 用户名与 GitHub noreply 邮箱署名；不使用私人邮箱。仓库从独立副本创建，不继承原项目的提交历史。

运行产生的资料和活动摘要应留在 data/，该目录由 .gitignore 排除。日志、常见数据库、简历文档、私钥等也有忽略规则。不要将个人文件放入 examples/；这里的文件会公开。

后续使用时，模型请求的摘要可能含有个人信息，即使没有完整保存回答也应谨慎处理。上传新改动前请检查暂存文件和截图；忽略规则不能代替检查。

此记录说明本次发布检查的范围，不保证以后自行加入的文件一定没有隐私内容。
