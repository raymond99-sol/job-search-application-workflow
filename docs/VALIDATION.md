# 本地验证记录

日期：2026-10-16。环境：macOS / Apple Silicon / Python 3.13.3。

## 已验证

- 使用 setup.sh 创建独立虚拟环境，安装 requirements.txt 成功。
- 在新环境运行完整测试：**14 passed**。
- 流式转发内容保持一致，本地请求记录、云端标记模型排除；每次只转发一次。
- gzip、deflate、zstd 压缩完成识别，以及压缩请求解码。
- 请求进行中可读到忙碌状态，完成后活动数量归零；取消和错误不会冒充完成。
- 记录线程遇到阻塞或权限异常时，请求提交／模型返回保持可用。
- 模拟代理关闭后，上游直连仍可使用；重启代理后，新请求可被记录。不是透明自动故障回退。
- 25 条记录上限与磁盘保留；数据文件变化后的统计、资料数量和待确认问题移除。
- 用独立端口启动示例界面，在浏览器查看国内／美国记录、合计与待确认内容；页面每秒刷新。

- 按新指南的真实 records 命令验证：空白工作区 → 待处理记录 → 待确认问题 → 保存本人答案 → 问题移除与事实计数更新 → 依据模拟确认更新同一申请，数量不重复增长。
- 起草使用真实 draft 执行入口与隔离模型替身：读取个人资料／岗位文件 → 代理出现忙碌 → 输出草稿 → 活动归零 → 完成摘要保存；请求只执行一次。
- 确认资料后写入问题清单失败时，问题仍显示；修复后重复保存不会生成重复事实。
