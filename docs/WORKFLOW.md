# 如何配合 Work 使用

1. 本人提供真实资料、岗位和任务范围。
2. Work 判断哪些部分可以交给本地模型，例如提取岗位要求、比较已确认经历、起草材料。
3. 本地模型通过明确配置的监测地址回答请求；面板显示该请求的摘要和状态。
4. Work 或本人审核输出，不能把模型猜测当成事实。需要本人确认的问题写入 pending.json，确认后更新 profile.json 并将该问题标记 resolved。
5. 仅在取得真实提交确认后更新申请记录。本参考版不执行投递，也不自动读取另一个聊天的记录。

可以让本机 Work 调用 `python -m career_desk.draft` 来尝试起草流程。该命令的参数、运行方式见 README。示例不是全功能 Agent，浏览器执行器及招聘网站适配没有包含在参考版中。

此分工可能减少重复劳动；具体速度和云端使用额度变化取决于模型、硬件、任务和审核次数，本项目没有做节省比例测量。
