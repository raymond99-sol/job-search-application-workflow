# Work 与本地模型的分工

要从头搭建，请阅读 **[完整操作指南](START_HERE.md)**。它包含环境安装、模型运行、个人资料、新聊天接入、起草、审核、待确认和记录更新的全部步骤。

| 角色 | 负责什么 |
|---|---|
| 本人 | 提供真实资料、回答未知问题、审核并确认最终提交 |
| Work | 分派任务、核对资格和事实、审核本地输出、维护记录 |
| 本地模型 | 根据明确输入整理内容和起草材料 |
| 工作台 | 显示已接入请求状态、最近完成记录、申请统计和待确认事项 |

入口：[首次接入指令](../prompts/WORK_STARTER.md) / [日常岗位指令](../prompts/DAILY_TASK.md)。

参考版不附带通用招聘网站自动填写器；模型生成文字不等于操控网页。网页填写可以由本人完成，或在另外配置并授权后由具备相应工具的 Work 完成。

此分工旨在减少重复劳动。速度、质量和 ChatGPT 使用额度变化取决于模型、硬件、任务和审核次数，没有节省比例保证。
